# Rackdog Homebrew Tap

Official Homebrew tap for [Rackdog](https://rackdog.com) tools.

## Install dogctl

```bash
brew install rackdog/tap/dogctl
```

Or tap first and install separately:

```bash
brew tap rackdog/tap
brew install dogctl
```

## Usage in a Brewfile

```ruby
tap "rackdog/tap"
cask "dogctl"
```

## Updating

```bash
brew update && brew upgrade dogctl
```
